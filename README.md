# Mái Nhà Nhỏ

Trang web tĩnh giới thiệu dịch vụ nhận nuôi mèo.

## Cấu trúc

- `index.html`: Nội dung và bố cục trang.
- `css.css`: Giao diện và responsive.
- `assets/images/`: Hình ảnh được trang web sử dụng.
- `CHANGELOG.md`: Lịch sử thay đổi.
- `RELEASE.md`: Thông tin phát hành.
- `AI_LOG.md`: Ghi chú ngắn về hỗ trợ AI.

## Chạy dự án

Mở `index.html` trực tiếp bằng trình duyệt hoặc chạy một máy chủ tĩnh tại thư mục dự án.

Khi triển khai, các tệp hình ảnh cần được đặt đúng các đường dẫn `assets/images/banner.jpg` và `assets/images/cat1.jpg` đến `cat9.jpg`.
